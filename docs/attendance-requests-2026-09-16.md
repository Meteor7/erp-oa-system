# 请假、加班及调休（2026-09-16）

## 已实现规则

- 仅事假在流程完成时按每日小时数扣减员工对应月份的填报上限；撤回后自动恢复。半天事假扣4小时，即0.5个工作日。病假、年假、婚假、产假、陪产假、丧假、其他假及加班、调休不扣减月度上限。
- 一天按现有工时口径折算为8小时。新申请记录每日小时数，支持零散时长与跨月，最长366天；请假及调休按员工工作日历填报，加班可选择休息日。
- 加班申请提交即1:1计入调休额度。调休提交时占用，完成后转为已使用，退回申请人或撤回时释放。退回先前审批节点而流程仍进行时继续占用。
- 加班额度撤回后，如已有占用或已使用调休，保留使用记录并显示负余额；不能继续新增调休，恢复有效加班额度后可继续使用。
- 三类申请复用请假审批路线、组织账号解析、权限开关、通知与抄送。小时数在服务端校验，余额以员工为单位加锁，重复审批不会重复计入。
- 历史仅有起止日期且类型明确为事假的已完成 OA 请假，按期间工作日每天8小时扣减；不会猜测历史半天假。空类型及其他类别不自动视为事假。
- 月度页面显示日历工时、已批请假扣减、剩余上限和已填超限提示；补批请假超限时也提示审批人处理。

## 请假分类与年假余额更新

- 仅事假扣减月度上限，其他类别均不扣减；未知/空类型的历史记录不自动归为事假，新申请必须选择类别。“其他假”在事由中直接说明，不区分带薪/无薪。
- 年假根据员工 date_of_joining 自动计算：满12个月发放40小时，此后每个入职周年增加40小时；余量累计保留，不清零。2月29日入职在非闰年按2月28日作为周年日。
- 展示累计发放、申请中占用、已用、可用和下次发放日期。OA年假申请是余额明细来源；草稿不占用，提交占用，通过转已用，退回申请人或撤回释放。不会重复记账，不挪用调休余额。
- 未满12个月或缺少入职日期不能提交年假；余额不足不能提交，也不能提前使用未来周年额度。缺少入职日期不影响其他类别申请。
- 员工锁与当前请求查询保护并发申请；请假日期上的累计使用不能超过该日期已获得的额度。自动累计额度不依赖定时任务。
- 正式库上线前无历史OA请假记录；系统可核算的已用余额以OA记录为准，系统外历史年假使用需要据实补录。薪资算法和其他年假制度不在本次范围内。
