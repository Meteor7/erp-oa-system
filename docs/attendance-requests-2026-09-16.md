# 请假、加班及调休（2026-09-16）

## 已实现规则

- OA 请假在流程完成时按每日小时数扣减员工对应月份的填报上限；撤回后自动恢复。加班和调休不参与月度上限计算。
- 一天按现有工时口径折算为8小时。新申请记录每日小时数，支持零散时长与跨月，最长366天；请假及调休按员工工作日历填报，加班可选择休息日。
- 加班申请提交即1:1计入调休额度。调休提交时占用，完成后转为已使用，退回申请人或撤回时释放。退回先前审批节点而流程仍进行时继续占用。
- 加班额度撤回后，如已有占用或已使用调休，保留使用记录并显示负余额；不能继续新增调休，恢复有效加班额度后可继续使用。
- 三类申请复用请假审批路线、组织账号解析、权限开关、通知与抄送。小时数在服务端校验，余额以员工为单位加锁，重复审批不会重复计入。
- 历史仅有起止日期的已完成 OA 请假，按期间工作日每天8小时扣减；不会猜测历史半天假。已有类型明确为调休的历史单据不扣上限。
- 月度页面显示日历工时、已批请假扣减、剩余上限和已填超限提示；补批请假超限时也提示审批人处理。
