# Rayher I18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a small Frappe-native Chinese/English/French language switching layer for the Rayher custom app.

**Architecture:** Use Frappe's native `User.language`, `frappe.local.lang`, `_()` runtime translation, and app package CSV files. Keep business enum values unchanged in this version; translate Rayher UI labels, report headers, exception labels, and server messages.

**Tech Stack:** Frappe Framework v15, ERPNext v15, HRMS v15, Python, pytest, CSV translation files.
